# Royal Frame Interiors: demo website

Demo website for Royal Frame Interiors, built to the studio brand kit: Ink #000000 on Paper #FFFFFF, Playfair Display and Inter, no colour anywhere.

Live: https://kreeates.github.io/royalframe-interiors/

Interactive pieces: project filters with a lightbox, a working frame composition tool, service accordions and a live budget estimator. Photography is from Unsplash and is shown for layout; the live site should carry the studio own project photographs.
